# Jiku - Prompts para Generacion de Material de Marketing

> **Marca:** Jiku (軸 = eje/axis)
> **Tagline:** "El eje de tu negocio"
> **Colores:** Jade Green (#4ADE80), Negro (#09090b), Blanco (#fafafa)
> **Tipografia:** Sora (headings), Cormorant Garamond (display)
> **Estilo:** Dark mode, glassmorphism, minimalista, premium
> **Audiencia:** Barberias, salones, spas, studios fitness, consultorios en Argentina

---

## CONTEXTO PARA TODAS LAS GENERACIONES

Usa este bloque como prefijo o contexto en cualquier prompt de imagen/diseño:

```
Jiku es una plataforma SaaS argentina de gestion de turnos y crecimiento para negocios de servicios (barberias, salones, spas, fitness). Su identidad visual es dark mode con acentos en jade green (#4ADE80), estetica minimalista premium con efectos glassmorphism. La tipografia es moderna y limpia (Sora). El logo es la palabra "jiku" en jade green. El kanji japones 軸 se usa como simbolo complementario. La marca transmite automatizacion, profesionalismo y crecimiento.
```

## NOTAS GENERALES PARA DISEÑADORES / IAs

1. **Nunca usar fotos stock genericas.** Preferir iconografia, mockups abstractos o ilustraciones minimalistas.
2. **El jade green (#4ADE80) es sagrado.** Siempre debe aparecer como color de acento. Nunca usar otro verde.
3. **El fondo siempre es oscuro.** Negro (#09090b) o gris muy oscuro (#18181b). Jiku no tiene version light en su branding.
4. **Menos es mas.** Si dudas entre agregar o quitar un elemento, quita. La marca respira.
5. **El kanji 軸 es un asset diferenciador.** Usarlo como elemento decorativo le da sofisticacion y lo diferencia de cualquier otra plataforma de turnos.
6. **Tipografia:** Sora para titulos, sans-serif limpia para cuerpo. Nunca usar tipografias decorativas o script.
7. **Idioma:** Español argentino. Usar "vos" en vez de "tu". Usar modismos locales cuando sea natural.
8. **Siempre incluir CTA.** Cada pieza debe tener una accion clara: QR, URL, o "Empeza gratis".
